졸업 초대장 웹앱 - GitHub Pages 배포용

배포 방법
1. 압축을 풀고 index.html을 저장소 최상위 폴더에 업로드합니다.
2. GitHub 저장소의 Settings > Pages로 이동합니다.
3. Build and deployment에서 Deploy from a branch를 선택합니다.
4. 배포할 브랜치(예: main)와 /(root)를 선택하고 Save를 누릅니다.
5. Pages 배포가 완료되면 제공되는 주소로 접속합니다.

이미지와 스타일은 index.html에 포함되어 있어 별도 에셋 파일은 필요하지 않습니다.
QR 코드 및 초대장 이미지 저장 기능은 외부 CDN 스크립트를 불러오므로 해당 기능 사용 시 인터넷 연결이 필요합니다.
